# 🚀 Jonathan Jose Rangel Betancourt - Página Web Profesional

Bienvenido al repositorio de mi página web profesional, un sitio moderno y responsivo diseñado para ofrecer y gestionar servicios de software especializados en licencias de Windows y Microsoft Office. El sitio integra un sistema de carrito de compras y automatización de pedidos vía WhatsApp, pensado para facilitar la adquisición de productos y optimizar la experiencia del cliente.

## 🌟 Características Principales

- **Interfaz Moderna:** Diseño profesional con animaciones suaves y atractivas.
- **Responsive Design:** Totalmente adaptable a dispositivos móviles, tabletas y escritorio.
- **Carrito de Compras:** Sistema de e-commerce simple, intuitivo y eficiente, con persistencia de datos usando LocalStorage.
- **Integración con WhatsApp:** Automatización del proceso de pedidos para mayor rapidez y comunicación directa.
- **Catálogo Especializado:** Venta exclusiva de licencias genuinas de Windows y Microsoft Office.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica y accesible.
- **CSS3:** Estilos modernos y responsivos, uso de variables CSS, y animaciones.
- **JavaScript:** Interactividad, gestión de carrito y lógica del e-commerce.
- **LocalStorage:** Persistencia de los datos del carrito sin necesidad de backend.
- **Font Awesome:** Iconografía visualmente atractiva y profesional.
- **Google Fonts:** Tipografías optimizadas y modernas para una mejor experiencia de lectura.

## 📁 Estructura del Proyecto

- `/index.html`: Página principal y punto de entrada.
- `/css/`: Hojas de estilo CSS personalizadas y librerías externas.
- `/js/`: Scripts JavaScript para la funcionalidad del carrito y la interacción de usuario.
- `/assets/`: Imágenes, íconos y otros recursos estáticos.

## 🔗 Despliegue

Puedes ver la página en funcionamiento desplegada en GitHub Pages o en tu servidor local clonando este repositorio.

## 💡 Cómo Usar

1. Clona este repositorio en tu máquina local.
2. Abre `index.html` en tu navegador.
3. Navega por los productos, añádelos al carrito y realiza pedidos a través de WhatsApp.
